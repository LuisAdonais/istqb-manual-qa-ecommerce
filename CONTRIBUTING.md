# Contributing

This is a personal QA portfolio project by **Luis Malave**.

It documents a complete STLC cycle applied to an e-commerce SUT,
following ISTQB CTFL v4.0 and CT-GenAI v1.1 standards.

---

## Found something?

If you spot an error in any artifact, a broken link, a traceability
inconsistency, or a formatting issue, feel free to open an **Issue**.

**Please include:**

- The artifact ID and file path (e.g. `03-test-design/test-cases.md` · **`TC-05`**)
- A short description of what you found
- Expected vs. actual content
- The ISTQB standard section reference, if applicable

---

## Pull Requests

Pull Requests are welcome for:

- Typo and grammar fixes
- Broken link corrections
- Formatting inconsistencies

For content changes (test cases, requirements, defect reports), please
open an Issue first to discuss the proposed change before submitting a PR.

---

## Language

- The `main` branch is written in **English**.
- The `es/main` branch is written in **Spanish**.

Please submit Issues and PRs in the language of the branch you are
referencing. Either language is welcome.

---

## A note on scope

This portfolio covers **manual functional testing** only.
API testing, test automation, and SQL validation are not part of this
repository — they are being developed in separate repositories.
